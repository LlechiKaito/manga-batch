# ユーザーストーリー一覧

## 前提
- 対象: 漫画（画像ベース）のepubファイル
- 目次は epub 内の画像ページとして存在する
- 「話」＝第1話、第2話等のエピソード単位（目次で分割されている単位）
- 1つのepubに複数話がまとまっている（単行本形式）
- バッチは手動実行
- 検証用途（S3にテスト用作品を1つ配置）

---

## US-1: S3からepubファイルを取得する `[manga-batch]`

**ストーリー**
運用者として、S3バケットに保存されたepubファイルを取得したい。それにより、後続の目次解析・分割処理を行えるようにする。

**受入条件**
- [ ] 指定したS3バケット・キーからepubファイルをダウンロードできること
- [ ] ダウンロードしたepubファイルをローカルの一時領域に保存できること

---

## US-2: epubの目次画像を読み取り「話」の一覧を特定する `[manga-batch]`

**ストーリー**
運用者として、epubファイル内の目次ページ（画像）を読み取り、収録されている「話」の一覧を把握したい。それにより、分割の単位を決定できるようにする。

**受入条件**
- [ ] epubファイルを展開し、目次に該当する画像ページを特定できること
- [ ] 目次画像からOCR等を用いて「話」のタイトル一覧（例: 第1話、第2話…）を抽出できること
- [ ] 抽出結果として話数とタイトルのリストが得られること

---

## US-3: 各「話」の開始ページと終了ページを特定する `[manga-batch]`

**ストーリー**
運用者として、epub内の各「話」がどのページからどのページまでかを特定したい。それにより、正確にepubを分割できるようにする。

**受入条件**
- [ ] 目次情報をもとに、各「話」の開始ページ（画像ファイル）を特定できること
- [ ] 各「話」の終了ページ（次の話の開始ページの直前）を特定できること
- [ ] 全ページが漏れなくいずれかの「話」に割り当てられること

---

## US-4: epubファイルを「話」ごとに分割する `[manga-batch]`

**ストーリー**
運用者として、元のepubファイルを「話」単位で分割し、話ごとの独立したepubファイルを生成したい。それにより、話単位での配信・管理が可能になる。

**受入条件**
- [ ] 各「話」に該当するページ（画像）のみを含む新しいepubファイルを生成できること
- [ ] 生成されたepubファイルが有効なepub形式であること

---

## US-5: 分割したepubファイルをS3に格納する `[manga-batch]`

**ストーリー**
運用者として、分割後の「話」ごとのepubファイルをS3バケットに保存したい。それにより、分割結果を永続化し利用可能にする。

**受入条件**
- [ ] 分割された各epubファイルがS3バケットにアップロードされること
- [ ] アップロード先のキーから、どの作品のどの話かが判別できること
