# 技術設計書: 漫画epub分割バッチ

## 技術スタック
- **言語**: TypeScript / Node.js
- **実行環境**: AWS Lambda
- **ストレージ**: Amazon S3
- **画像解析**: OpenAI GPT API（Vision）

---

## アーキテクチャ概要

```
S3 (入力)          Lambda                    S3 (出力)
┌──────────┐     ┌──────────────────────┐    ┌──────────────────┐
│ manga/   │────>│ 1. epub取得          │    │ manga/output/    │
│  vol1.epub│     │ 2. epub展開          │    │  vol1_ep01.epub  │
│           │     │ 3. 目次画像→GPT API  │───>│  vol1_ep02.epub  │
│           │     │ 4. 話の範囲特定      │    │  vol1_ep03.epub  │
│           │     │ 5. epub分割・生成    │    │  ...             │
│           │     │ 6. S3アップロード    │    │                  │
└──────────┘     └──────────────────────┘    └──────────────────┘
```

## 処理フロー詳細

### Step 1: S3からepubファイル取得（US-1）
- S3バケット・キーは環境変数またはイベントパラメータで指定
- `@aws-sdk/client-s3` を使用してepubファイルをダウンロード
- Lambda の `/tmp` ディレクトリに保存

### Step 2: epub展開・目次画像の特定（US-2）
- epubはZIP形式のため、`adm-zip` 等で展開
- epub内の画像ファイル一覧をコンテンツ順序（spine）に基づき取得
- 目次ページの特定:
  - 作品によって目次の位置・形式が異なるため、GPT APIで判定する
  - 先頭から一定数のページ（例: 最初の10ページ）をGPT APIに送り、「目次ページはどれか」を判定させる

### Step 3: GPT APIで目次画像を解析（US-2）
- 目次と判定されたページ画像をBase64エンコードしてGPT-4o（Vision）に送信
- プロンプトで「話」のタイトル一覧をJSON形式で返すよう指示
- レスポンス例:
  ```json
  {
    "episodes": [
      { "number": 1, "title": "第1話 タイトル" },
      { "number": 2, "title": "第2話 タイトル" }
    ]
  }
  ```

### Step 4: 各話の開始・終了ページ特定（US-3）
- 作品によって話の境界の視覚的特徴が異なるため、GPT APIで判定する
- 1冊あたり約180ページ
- **効率化のため、バッチ方式で判定**:
  - 全ページを一度に送るのはコスト・トークン制限の観点から非効率
  - 10ページずつのグループに分け、各グループをGPT APIに送信
  - 「このページ群の中に新しい話の開始ページはあるか？あればどのページか」を判定させる
  - 約18回のAPI呼び出しで全ページをカバー

### Step 5: epubファイルの分割・生成（US-4）
- 各話の開始〜終了ページの画像を取り出す
- 話ごとに新しいepubファイルを構築:
  - `mimetype`, `META-INF/container.xml`, `content.opf`, 各画像ファイル
  - epub生成には最低限の構造をテンプレートとして組み立てる
- `/tmp` に一時保存

### Step 6: S3へアップロード（US-5）
- 生成した各epubファイルをS3にアップロード
- 格納パス例: `manga/output/{元ファイル名}_ep{話数}.epub`

## プロジェクト構成（案）

```
manga-batch/
├── src/
│   ├── handler.ts          # Lambda ハンドラー（エントリーポイント）
│   ├── s3.ts               # S3 操作（取得・アップロード）
│   ├── epub.ts             # epub 展開・生成
│   ├── gpt.ts              # GPT API 呼び出し（目次解析・ページ判定）
│   └── types.ts            # 型定義
├── package.json
├── tsconfig.json
└── aidlc-docs/
```

---

## 依存パッケージ
- `@aws-sdk/client-s3` — S3操作
- `adm-zip` — epub(ZIP)の展開・生成
- `openai` — GPT API呼び出し

---

## Lambda設定
- **ランタイム**: Node.js 20.x
- **メモリ**: 512MB（epub展開・画像処理のため）
- **タイムアウト**: 5分（GPT API呼び出しを含むため余裕を持たせる）
- **環境変数**:
  - `S3_BUCKET`: 対象バケット名
  - `S3_KEY`: 対象epubファイルのキー
  - `OPENAI_API_KEY`: GPT APIキー
